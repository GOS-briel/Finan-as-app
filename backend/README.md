# Backend

Servidor Flask mínimo do controle financeiro.

## Como rodar

```powershell
# A partir da raiz do projeto: ativar o ambiente virtual
..\venv\Scripts\Activate.ps1

# Instalar dependências (se ainda não instaladas)
pip install -r ..\requirements.txt

# Rodar o servidor
python main.py
```

Acesse http://127.0.0.1:5000/ — deve exibir "Olá, controle financeiro".
